CIDR:
- range of IP
- 192.168.0.1/24 -> 24 is length of network part

Virtual Private Cloud VPC:
- automatically preconfigured
- privately isolate services in public cloud
- use VPC CIDR

10.0.0.0 - network address
10.0.0.1 - default gateway
10.0.0.2 - amazon DNS
10.0.0.3 - future use
10.0.0.255 - broadcast address
